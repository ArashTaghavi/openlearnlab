
# OpenLearnLab

**Learn. Experiment. Understand. Build.**

OpenLearnLab is a free and open educational project dedicated to making technical concepts easier to understand through practical, hands-on learning.

The goal is not just to write code or use libraries. It is to understand how things work, why they work, when they fail, and how different approaches compare.

## Philosophy

Learning should go beyond theory and code execution.

At OpenLearnLab, we focus on:

- **Concepts:** Understand what a concept means and why it matters.
- **Examples:** Explore clear, practical, and reproducible examples.
- **From Scratch:** Build simplified implementations to understand how algorithms work internally.
- **Experiments:** Test different scenarios, datasets, and edge cases.
- **Comparisons:** Compare approaches, results, strengths, and limitations.
- **Interpretation:** Learn how to analyze outputs and make informed decisions.

## Topics

OpenLearnLab currently focuses on:

- Machine Learning
- Model Evaluation and Analysis
- Deep Learning
- Large Language Models
- Retrieval-Augmented Generation (RAG)
- AI Agents

The project may expand into other areas of software engineering and computer science.

## Project Structure

- `src/openlearnlab/` - Reusable Python implementations and utilities.
- `docs/` - Educational explanations and documentation.
- `notebooks/` - Interactive experiments and analyses.
- `examples/` - Practical standalone examples.
- `tests/` - Automated tests.

## Getting Started

Requires Python 3.14 or newer.

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/openlearnlab.git
cd openlearnlab
```

Create and activate a virtual environment:

```bash
python -m venv .venv
```

On Windows:

```bash
.venv\Scripts\activate
```

On Linux or macOS:

```bash
source .venv/bin/activate
```

Install the project:

```bash
python -m pip install -e ".[dev]"
```
